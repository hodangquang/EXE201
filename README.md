# REWEAR

Frontend React và Vite cho REWEAR, nền tảng thời trang tuần hoàn. Giao diện khách hàng và quản trị viên dùng chung dự án này.

## Chạy trên máy cá nhân

```powershell
npm.cmd install
npm.cmd run dev
```

Vite chuyển tiếp `/api` và `/uploads` tới backend tại `http://localhost:5000`. Backend không nằm trong thư mục này.

## Kiểm tra bản dựng

```powershell
npm.cmd run build
```

Đọc [context/README.md](context/README.md) để xem kiến trúc, màn hình, luồng dữ liệu và các phần còn dùng dữ liệu minh họa. Quy tắc làm việc và thương hiệu nằm trong [AGENTS.md](AGENTS.md).
