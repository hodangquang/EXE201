# QA giao diện và tăng tương tác — 2026-10-17

## Phạm vi

Kiểm tra source và giao diện các route ngoài Home; không thay backend/API, auth/cart state, route guard, quy tắc giá/tồn kho hoặc flow tạo đơn/thanh toán. Home được giữ nguyên. ReportsPage và StaffList chưa có route, chỉ kiểm tra source.

## Kiểm tra thực tế

- `npm.cmd run build`: đạt; 4021 modules, JS 1,961.53 kB (gzip 585.48 kB), CSS 165.87 kB. Còn cảnh báo chunk >500 kB.
- `npm.cmd run lint`: không chạy được phân tích vì thiếu eslint.config.* với ESLint 10.11.0; lỗi cấu hình có từ trước. Không tuyên bố lint đạt.
- `git diff --check`: kiểm tra khoảng trắng trên các thay đổi source/context.
- Không có test script trong package.json. Dùng Playwright/Chromium đã có trên máy, không thêm dependency hoặc framework test vào repo.
- Browser intercept toàn bộ `/api/**` bằng fixture tổng hợp, có sản phẩm tên dài và dữ liệu tài khoản/địa chỉ/đơn giả. Không đọc hoặc lưu phản hồi nhạy cảm; không gọi mutation backend thật.
- 148 ca render = 37 route/trạng thái × 375/768/1024/1440px, cao 1000px. Không pageerror, Vite error overlay hoặc document overflow; các vùng table/nav chủ đích cuộn được loại khỏi phép kiểm tra tràn ngang. Đây không phải kiểm tra mọi trạng thái hoặc mọi click trên mỗi route.

## Theo yêu cầu mới nhất: navbar ngoài Home giống Home

- Home là chuẩn visual, nên bỏ `StorefrontNavigation.css` global và override nền trắng/44px ngoài Home. PDP chuyển sang class `rw-nav`, Profile/World có đủ Search/Cart/Account; giữ back link PDP. Mobile ngoài Home có 2 hàng, menu cuộn và action icon để không làm link biến mất; Home mobile chưa thay.
- Playwright fixture kiểm tra `/`, `/new-in`, `/women`, `/men`, `/about`, `/world`, `/store/qa-product`, `/profile?tab=profile` ở 375/1440px: logo/menu/pill đều cao 38px, link 30px, nền `rgba(200, 200, 200, 0.35)`; các trang ngoài Home không tràn document. Search PDP đi đến catalog và cart drawer mở trên catalog/Profile; không có pageerror trong lượt tương tác. `npm.cmd run build` thành công với cảnh báo bundle lớn.
- Giới hạn: Home mobile menu bị ép còn khoảng 10px ở 375px trong chính mã gốc; task này không chỉnh Home. API thật, browser/thiết bị khác, checkout/payment header riêng chưa kiểm thử lại.
